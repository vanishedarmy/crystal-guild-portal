# Hosting Guide — Crystal Guild v1.7.0 Retainer Service Alpha 2

Deploy this Web tree with the matching `1.7.0-retainer-a2` Bot. Preserve hosted secrets and persistent state. `/api/health` should report runtime/frontend `1.7.0-retainer-a2`, hosted sync **1**, and Portal protocol **31**.

Retainer Service adds no new hosted environment variable. The local Bot remains the authoritative writer for dispatch, timers, committed rewards, and collection.
