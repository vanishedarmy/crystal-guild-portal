# Crystal Guild v1.1.18 — Inventory Identity Phase 2

Frontend asset revision: `1.1.18-retro-phase-ii32`

This Web-only visual pass packages every generated Inventory Identity sheet created after Phase 1 as individual transparent 256×256 WebP assets. The pass adds 136 new reusable family/tier icons: 20 ores/metals, 8 elemental crystals, 12 weapon-family bases, 36 weapon-tier variants, 36 armor-tier variants, and 24 armor/accessory family variants. Together with the existing 32 consumables, the Web package now carries 168 item/equipment art assets.

Weapons and armor resolve through reusable family/tier mappings, accessories use generated boot/belt/ring/gauntlet/helm families, and matching ore/metal/crystal/core materials receive artwork. Monster-part materials are intentionally left for the later monster-parts artwork wave instead of being assigned misleading metal/crystal art.

Shared ItemArtwork is also wired into Guild Blacksmith recipe outputs, illustrated recipe materials where available, and Forge Gear cards.

No Bot, database, hosted-sync schema, Portal Action protocol, OAuth, or player-data change is required.
