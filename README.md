# Crystal Guild Web — v1.7.0 Retainer Service Alpha 2

Current Web baseline: Retainer Service Alpha 2 Artwork & UI Hotfix 2. Runtime remains `1.7.0-retainer-a2`; frontend asset revision is `1.7.0-retainer-a2h2`, paired Bot schema **15**, hosted sync **1**, Portal protocol **31**, with the existing v1.6.0 MGP/Gold Saucer production baseline preserved.

Retainer Service adds a personal Portal-only procurement desk with optional targeted material procurement. Dispatch one Retainer with Gil, optionally nominate a Priority material from that route, wait for the persisted assignment timer, then collect the committed crafting-material haul and Retainer EXP. Alpha 2 also keeps the eight most recent collected hauls. Rewards are fixed before departure and collection is exactly-once.

See `RELEASE_NOTES.md`, `UPGRADE_GUIDE.md`, and `VALIDATION_REPORT.md`.

Hotfix 2 restores the intended 12-column Retainer layout and hard-bounds the Moogle profile portrait so the profile panel cannot expand into the oversized presentation seen in Hotfix 1.
