Hosted Web runtime: `1.1.18-retro-phase-ii` · frontend asset revision `1.1.18-retro-phase-ii37` · hosted sync schema **1** · Portal Action protocol **14**.

This package is the SNES Item Regeneration checkpoint for CG-ITEM-R01 through CG-ITEM-R06. The regenerated consumables, battle items, crafting materials, and rare monster materials are packaged as separate transparent 512×512 PNG assets under cache-busted inventory-art directories. Superseded inventory-art directories have been removed from the full build. Equipment artwork remains on the existing Phase 2 system until the CG-GEAR waves are integrated.
