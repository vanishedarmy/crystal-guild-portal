# Crystal Guild v1.2.0 — Expeditions Beta 2

Beta 2 is the v1.2 UX consolidation pass. Gameplay remains on the validated Beta 1 balance baseline while the Portal prioritizes current activity, reduces secondary visual weight, and keeps the page anchored when players open or close detail cards and expandable sections.

## Highlights
- Viewport-preserving detail dialogs and collapsible sections.
- Player Guide catalog panels no longer force-scroll on open/close.
- Adventure Board current-activity summary and action-first reading order.
- Independently collapsible Expedition Atlas detail.
- Existing Beta 1 Bot remains compatible.
