Crystal Guild Web v1.1.18 — Retro Phase II
Frontend asset revision: 1.1.18-retro-phase-ii25

Pixelify Sans Typography Pass adds a readable retro display typeface to major page titles, character names, Bestiary/boss identities, and Player Guide headings while leaving body text and dense UI content on the existing clean font stack.

Pixelify Sans is loaded through Google Fonts with a local fallback. The Privacy Policy and Content Security Policy have been updated accordingly.

No Bot update, DB migration, OAuth change, environment-variable change, or player reset is required.
