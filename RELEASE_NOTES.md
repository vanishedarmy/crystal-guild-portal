# Crystal Guild v1.2.0 — Expeditions Alpha 2 Hotfix 4

## Scenic Backdrop Fit Fix

This Web-only hotfix corrects how the new scenic backdrops fit within their tab panels.

## Fixes
- **Relic Arsenal** backdrop now fills the full panel height instead of stopping early and leaving a blank lower section.
- **Solo Venture** backdrop uses the same full-panel scenic treatment for consistent behavior.
- Scenic panel alignment has been adjusted so the background art sits more naturally within the available tab space.

## Compatibility
- Bot runtime unchanged from Alpha 2.
- No database migration required.
- Safe in-place web update.
