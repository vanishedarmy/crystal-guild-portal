# Crystal Guild v1.6.0 — Gold Saucer Alpha 2 Web

Alpha 2 adds the playable **Monster Toss** workspace to the existing Gold Saucer tab while retaining the Alpha 1 H1 scenic artwork and H2 Mini Cactpot / Crystal Slots polish.

- Five-throw persistent Monster Toss UI with target and throw-style selection.
- Displays current score, remaining throws, throw history, daily games remaining, UTC reset timer, and score reward tiers.
- Personal Saucer Ledger adds Monster Toss games, best score, accuracy, and best payout.
- Prize Counter presents two additional cosmetic-only titles from the authoritative Bot state.
- Mini Cactpot and Crystal Slots behavior/visuals remain unchanged.

Hosted/frontend/compatible Bot runtime: `1.6.0-gold-saucer-a2`. Local schema **12**, hosted sync **1**, Portal protocol **27**, prefix `!`.
