# Crystal Guild v1.1.18 — Retro Phase II
## Cinzel Typography Pass

This Web-only visual pass replaces Pixelify Sans with Cinzel for Crystal Guild's major display and identity typography. The scope remains intentionally limited so body copy, stats, tables, forms, and dense interface text stay highly readable.

### Cinzel display areas
- Guild Heroes and Adventurer Portal identity headings
- Major page and section titles
- Character display names
- Bestiary monster names
- World/Raid Boss names and detail headings
- Major Player Guide headings

### Readability
- Existing mobile no-wrap and responsive name-fit protections remain active.
- Body text and dense UI content continue using the existing clean UI font stack.
- Cinzel loads through Google Fonts with the existing local fantasy serif fallbacks if the remote font is unavailable.
