# Crystal Guild v1.7.1 — Resynthesis Alpha 2 Hotfix 5

## Venture & Equipment UX — final UI corrections
- Stream/Rally Ventures are **100% Encounter / 0% Treasure Chest**.
- Solo Venture remains its separate **80% Encounter / 20% Treasure** system.
- Overview and Streamer Recent Activity panels remain collapsible.
- Equipment shows item level and held gear sorts highest item level to lowest.
- Own-profile Favorites remain a separate browser-local gear section.
- Favorite controls are icon-only **☆ / ★** with accessible labels.
- Named “Replaces X” comparison copy remains removed.
- **Weapons and Armor** now share the same Best use presentation: `Best: <Job> · Also: <other compatible Jobs>`.
- Best use appears on Equipment inventory cards, Current Loadout, item detail, and Moogle Emporium Buy/Sell gear. Job order comes directly from the existing item compatibility-priority list.
- Equipment-card layout is constrained to prevent the prior tall/narrow stretching behavior.

Runtime/frontend remains `1.7.1-resynthesis-a2h5`; paired Bot remains `1.7.1-resynthesis-a2h5`; schema **15**; hosted sync **1**; Portal protocol **32**. No migration or player reset.
