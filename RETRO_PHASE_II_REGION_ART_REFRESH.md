# Crystal Guild v1.1.18 — Retro Phase II Region Art Refresh

The eight live Adventure Board regions now use newly generated, higher-detail SNES-era JRPG-inspired scenes at a new cache-busting asset path: `/retro-phase-ii/regions-hd/`.

The prior simplified region-art directory is intentionally removed from this build. Frontend asset revision is `1.1.18-retro-phase-ii2` so deployed clients request the new visual layer rather than reusing cached art.

No Bot, database, sync schema, Portal Action protocol, OAuth, or gameplay behavior changes are included.
